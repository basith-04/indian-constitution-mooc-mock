# Constitution of India — MOOC Mock Test

A simple web-based mock test created to help students prepare for the **Constitution of India MOOC examination**.

The mock test was built using the **200-question question bank provided for the course**, allowing students to practice the questions in an exam-style format before the final examination.

## About

This project was originally created as a quick study tool for students in my college during the MOOC examination period.

It was used by **100+ students** for exam preparation.

## Features

- Questions based on the official 200-question course question bank
- Simple mock-test interface
- Instant scoring
- Lightweight single-page application
- No login or account required
- Works on both desktop and mobile

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase Hosting

## Purpose

The goal of this project was simple: turn a large question bank into an easier and more practical way for students to prepare for the exam.

Instead of repeatedly going through the question bank manually, students could take mock tests and quickly evaluate their preparation.
